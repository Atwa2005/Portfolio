SOAR-Style Automated Incident Response Pipeline

An end-to-end detection-to-response workflow built in n8n that ingests Wazuh alerts, enriches IP and hash indicators with threat intelligence, and routes each case into either autonomous containment or analyst review when confidence is lower.

Technologies

Wazuh · n8n · AbuseIPDB API · VirusTotal API · Gmail

Objective

Reduce response time from alert to containment while keeping a human-in-the-loop path for ambiguous alerts

Challenge

Automating containment without over-blocking on low-confidence indicators

Solution

Indicator-type routing, confidence-based branching, and callback approvals for analyst confirmation
